🌤️ Weather App

A simple and clean Weather App built using HTML and CSS. It provides a user-friendly interface to display weather information for a selected location.

✨ Features

* 🔍 Location search box
* 🌡️ Temperature display
* ☁️ Weather condition
* 🌡️ Feels-like temperature
* 💧 Humidity
* 💨 Wind speed
* 👁️ Visibility
* 🕐 Observation time
* 🎨 Clean and modern UI

🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox

📁 Project Structure

Weather-App/

🚀 How to Run

1. Clone this repository:

git clone YOUR_REPOSITORY_LINK

2. Open the project folder.
3. Open index.html in your browser.
